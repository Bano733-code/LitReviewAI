# LitReviewAI: Automated Research Paper Reviewer 📚🤖  

**Smarter Reviews, Faster Insights.**  

LitReviewAI is an AI-powered app that helps researchers, students, and professionals review academic papers in seconds. Just upload a PDF and get a structured review with summaries, strengths, weaknesses, and suggested improvements.  

---

## 🚀 What it does
- 📄 Upload a research paper (PDF)  
- 🔎 Summarizes contributions automatically  
- ✅ Identifies strengths and weaknesses  
- 💡 Suggests improvements  
- 🔑 Extracts keywords & related topics  
- 🌍 Supports multiple languages  

---

## ▶️ How to use
1. Upload your **PDF research paper**.  
2. Select the type of review (summary, critique, keywords).  
3. Get an **AI-generated review report** instantly.  

---

## 🛠️ Built with
- **Streamlit** for the UI  
- **GROQ API** for summarization and critique  
- **PyMuPDF (fitz)** for PDF parsing  
- **KeyBERT** for keyword extraction  
- **Deep Translator** for multilingual support
